# Data directory

This directory is separated into raw source data and generated experiment artifacts.

```text
data/
├── raw/
└── processed/
```

- `raw/`: authorized MIMIC source files plus the auxiliary NDC/RxNorm/ATC, molecular-structure index, and DDI mapping resources required by the supplied preprocessing scripts.
- `processed/`: serialized vocabularies, complete patient records, DDI adjacency matrices, and taxonomy hypergraph matrices generated by `src/processing_mimic_iii.py` and `src/processing_mimic_iv.py`. Train/validation/test splitting is performed at runtime by the experiment scripts.

MIMIC-derived data should not be committed to a public repository. See the repository-level `README.md` for the exact expected filenames and preprocessing commands.
